# 🗺️ Manga Translator

Автоматический офлайн-переводчик манги с японского на русский язык. Программа автоматически распознает текст, очищает оригинальные сканы и накладывает перевод прямо поверх исходного изображения (In-painting / Text Overlay) с сохранением контекста.

## 📊 Производительность (Бенчмарки)

> **Конфигурация тестового стенда:**  
> 💻 **GPU:** RTX 3060 12GB VRAM | **RAM:** 32GB

Время перевода одной страницы в зависимости от выбранной LLM-модели и режима работы:


| Модель | Режим (Железо) | Время перевода | Примечание |
| :--- | :--- | :--- | :--- |
| **gemma-4-26b-a4b-it-ultra-uncensored-heretic** | GPU + CPU | **38 сек** | Максимальное качество |
| | CPU | **90 сек** | |
| **translategemma-12b-it-GGUF** | GPU | **13 сек** | Оптимальный баланс |
| | GPU (Асимметричный X2) | **11 сек** | Экономия за счет параллельных промптов |
| | CPU | **79 сек** | |
| | CPU (Асимметричный X2) | **74 сек** | |
| **translategemma-4b-it** | GPU (Асимметричный X2) | **7 сек** | Самый быстрый перевод |
| | CPU | **23 сек** | |

*💡 **Что такое асимметричный запрос?** При асимметричном запросе время экономится за счет параллельной обработки промптов нейросетью.*
